# 运行与验证边界

## 展示版

仓库根目录 `npm run demo`，Node.js 20+，无依赖。详见 [演示说明](demo.md)。

## 原始员工客户端前端

```bash
cd clients/employeeclient-desktop
npm ci --ignore-scripts
npm run build
```

开发页面可用 `npm run dev` 打开，但真实登录、消息、文件、推送与工作数据需要配置对应后台。目录里的历史 `dev:backend` 依赖旧工作区路径，本次快照没有按旧路径重新装配，不应当作开箱即用后台。

## 中枢服务

`modules/hub/package.json` 声明 Node.js >=24 <25，服务使用 PostgreSQL及单独的密钥与对象存储配置。入口位于 apps/hufu、apps/mem、apps/v8、apps/mcp、apps/worker；数据库结构与函数位于 migrations。

完整部署还需部署装配文件、角色初始化、服务配置、对象存储及身份提供方。此快照中的部分原构建脚本引用未导出的 deploy 文件；独立v8构建脚本也引用未随包导出的 .hub/build.sh。因此本次不提供未经验证的一键生产部署承诺，也不建议照旧脚本直接迁移现有数据库。

请先在隔离开发库核对迁移依赖、生成自己的密钥、配置各服务入口，再进行真实身份登录与跨服务验收。示例地址、示例UUID和空历史索引不能用于连接原生产系统。
