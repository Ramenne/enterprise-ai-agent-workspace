# 员工客户端 macOS 0.2.0 直接分发候选

分别提供 Apple Silicon（arm64）及 Intel（x64）DMG。拖入“应用程序”，打开后使用现有员工客户端账号登录。没有换聊天/上传/缓存服务，没有新增独立MCP配置。

本包为本地 ad-hoc 签名，未经 Apple Developer ID 签名或公证。首次下载后系统可能阻止打开：尝试打开一次后，在系统设置→隐私与安全性中核对员工客户端并选择“仍要打开”。不关闭全局 Gatekeeper，不安装来源不明的证书。此流程沿 Apple 官方说明：https://support.apple.com/en-au/guide/mac-help/mh40616/mac 。官方签名与公证需要 Apple Developer Program 资源，当前没有；本机授权不等同苹果颁发证书。Electron 官方发行指引：https://www.electronjs.org/docs/latest/tutorial/code-signing 。

已实现：常驻会话栏；Enter发送、Shift+Enter换行及中文输入法保护；选择/拖入/粘贴文件先待发、确认后自动上传与发送，无是否存储提示；会话行拖入指定收件人，保留其他会话草稿；最多6个待发文件，拒绝目录；原文件缓存、重试、幂等和附件加密沿既有路径。文件传输助手为本人会话，同账号客户端同步消息和文件，不引入电脑任务协作服务。

附件：文本/图片等沿原预览；一般格式交系统应用打开。菜单可另存为、用其他应用分享、准备拖出。已校验的文件可拖出；尚未获取的文件先准备完整字节，再启用拖出，不伪造浏览器拖拽链接。另存为只显示一次系统选址窗口；原生写入校验、落盘回读后才完成。系统分享只代表打开系统菜单，接收方送达不由员工客户端伪造确认。

关闭窗口保留进程，Dock/窗口菜单恢复；Command-Q退出。复用既有长连接及登录，不通过新轮询反复验证身份。进程退出、系统休眠后的持续通知未完成真实长期验收，不承诺强退仍可通知。

安全：sandbox、contextIsolation、webSecurity开启，Node关闭；主进程仅接受主窗口同源和不透明文件句柄，分片≤8MiB，校验大小/hash后系统交接，账号切换清理副本；不向页面开放任意文件路径读写。最多4个未完成副本/24个就绪副本。单账号内存文件准备不额外新增身份请求。外链走系统浏览器。包内前端保留同源HTTPS API，桌面不被PWA Service Worker或Android更新接管。

验证：实际arm64 .app的15项原生回归通过，新增7项场景通过，真实磁盘写入/系统打开/系统分享菜单/原生拖出调用已覆盖；双独立模拟客户端助手收发、断网补消息、相同模拟登录profile进程重启恢复通过。9项原生文件/保存测试通过，typecheck/build通过。模拟账号与本地提供方不等同正式账号/真机/跨日验收。Finder最终落点副本未实测；Intel只验证构建、Mach-O架构、签名与DMG完整性，本机无Rosetta，未执行Intel版。

HTTP集成接口已发布：https://employeeclient.example.invalid/business/v1/integration 。中枢单个employeeclient小工具源码已提交，但当前中枢工程目录缺少MCP边缘服务发布目标，未发布；不以产品HTTP可用冒充MCP已接通。

构建：npm run typecheck；npm run build；python3 desktop/build-macos.py arm64 或 x64。Electron44.9.0官方运行时校验SHASUMS，file-selector5.0.1源码与MIT许可证保留。原生日常维护树、PWA及Android版本不受本次桌面包发布覆盖。

### 2026-10-21 · macOS安装是可执行动作，不能只提示手动移动（0.2.9）
