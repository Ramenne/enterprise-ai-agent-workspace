# 增量采集与上下文接续

在已有知识上更新、换会话/换AI接手、来源追加或修订时读取。本文件给出有限接续方法，不要求另造采集平台或把每条知识绑定原文ID。

## 接续记录需要让下一AI知道什么

项目中已有进度/清单够用就沿用，不重复建账。阶段回顾先在该清单上恢复本阶段涉及的跨对话范围，不因V8提示只带工作/阶段定位就默认仅分析当前对话；使用阶段方法时见[阶段回顾与工具库闭环](phase-workflow.md)。来源覆盖、语义理解和工具库入库映射分别取其最新记录，旧覆盖记录的历史存放决定不覆盖后来的已确认入库事实。最小记录包括：

- 本次范围与项目关系，当前有效知识/历史分区入口及其版本或内容标识。
- 来源稳定身份及已覆盖范围；如会话ID和最后处理消息、固定文档版本、明确的导出范围，或本地JSONL完整记录边界。标题、文件mtime及“看过了”不能独立证明覆盖。
- 已获取但未读/已读未综合/已提交分别是什么；缺图、截断、继承重复、排除的续接摘要等限制。
- 上次最终判断、未决问题及涉及哪些知识；本轮应从哪处接续。只保影响下一步的简短背景，复杂细节按需回查。

源ID、读取位置和去重映射可在批次清单中统一保存，不要求每条知识附消息编号或长引文。知识正文仍需足够具体，不能让每次使用都重读原会话。

## 怎么确定只读哪些

先读本次任务和既有简短接续，检索相关知识正文，然后选下面路径：

| 情况 | 本次动作 |
|---|---|
| 原来源没有新增/改写，也没有新目标或反证 | 复用，零重采；必要时只完成未提交的判断 |
| 同一会话追加新消息 | 取上次已处理边界后的新消息；少量重叠只用于核边界/消解指代，并去重 |
| 新会话有父历史或转贴报告 | 沿稳定消息身份/父关系复用已处理部分，读本分支新增内容；转贴不当独立验证 |
| 新消息指“上次那个方案”，现有知识背景不足 | 先查对应知识/决定，再补原文相邻上下文；含义明确就停止扩读 |
| 新要求改变某入口/平台或与旧规则冲突 | 重读该对象的决定和必要理由，修受影响知识；不带动无关项目重采 |
| 固定文档出现新版本或旧消息被改写 | 对照确切版本/消息差异，并补必要上下文；失效的是受影响范围，不自动整库失效 |
| 来源边界缺失或无法验证 | 查旧报告/冻结清单恢复覆盖；不能恢复则标覆盖未知，读取与当前问题有关的最小范围，不假装已完成也不先重拉所有历史 |
| 用户明确要整轮重采，或证据说明原覆盖不可用 | 说明重采范围，复用完整原件重做语义判断，不把旧提炼当唯一输入 |

不用固定“回读20轮”或“每轮重跑26会话”。需要多少上下文按当前指代、冲突和决策信息是否充分判断；补读仍有缺失才扩范围，够用即停。全局方法变更可能影响多个项目，但先查实际受影响条目，不重新抓全部原件。

## 不同读取通道

远端接口支持since/after/cursor时用其真实契约。只有倒序分页时，从最新页向前读取至已知稳定边界或重复覆盖，核去重和分页完整性后停止；不能因接口没有增量参数就把所有旧页全部读完。请求数量受实际缺口限制，找不到边界则明确覆盖未知并改用获准的本地冻结资料或定向范围。

本地追加日志可保存完整行的字节边界及源身份。只有验证同一来源且旧前缀未被改写，才能从边界接读；文件变短、轮转、压缩/重建、旧消息编辑都不能盲信旧偏移。检查前缀的机械校验不等于让AI重新装载历史文本。末尾不完整JSON先保待续，不把边界推进到坏行之后。若所用工具不支持可靠续读，明确其限制，先复用已保存取材，不能声称脚本自动增量。

## 提交和成本

本轮只更新新增/修订/撤回的条目及必要关联，沿原知识ID。采集完成不能直接推进语义完成；原文保存后分析失败，下次从已保存原文继续，不重复下载。知识已写入而回执失败，先核原写入，不另造条目。项目知识暂缓入库时，更新本地知识和接续状态即可；不因Skill更新便擅自上传项目内容。

回执简记：沿哪个知识基线、哪些来源有变化、实际新读范围、为什么补读旧片段、改了哪些条目、下一边界和仍缺什么。没有新增有价值信息就如实零新增，不通过多写知识证明工作量。不承诺固定节省百分比；看实际是否减少重复读取并保持必要理解。

## 有限应用检查（构造情形）

- 已处理26会话，原会话新追加3条关于更新入口的纠正：读新3条和该入口原知识/必要决定，更新对应条目，不重抓26会话。
- 新3条讨论另一个无关项目：不重读员工客户端；为新项目定位现有知识和必要背景。
- 其中一条“取消它”指代不明：补读相邻内容直到对象明确，不能只为省Token猜对象，也不无条件重读所有历史。
- 上次只取材到末尾但最后5段没分析：复用已存5段完成分析，不能跳到“新增为零所以无事可做”。
- 原导出被替换且内容变短：旧字节边界失效，核版本差异/冻结备份，定向复核受影响知识，不能跳过被改写的决定。

以上是方法检验情形，不是独立AI试用结果。
