# 外部工具与进程边界

适用于会启动编译器、浏览器、FFmpeg、Python、OCR 或其他子进程的代码。

## 责任边界

- 调用方负责工具选择、固定参数、业务结果语义、输入输出预算和直接资源清理。
- Host 或平台负责统一取消、Worker 隔离以及确认属于本次运行的后代进程兜底。
- 任何组件都不得扫描、接管或终止归属不明的 PID。
- 模块或任务只管理自己启动的进程、stdio、句柄、临时文件和直接资源。

## 安全启动和取消

1. 启动前检查取消信号和截止时间。
2. 版本／能力探测使用相同取消信号和有界超时。
3. 探测返回后、正式启动前再次检查取消。
4. 使用明确可执行文件和参数数组，关闭 shell，不拼接不可信命令字符串。
5. 流式读取并在数据产生期间执行预算。
6. 取消或超时时停止继续工作，关闭直接资源并终止自己启动的子进程。
7. 子进程异常不能拖垮 Host 或其他任务。

## 相关验证

按改动覆盖启动参数、正常／异常退出、无输出、部分输出、取消、超时、资源超限和清理。Mock 可验证分支；声称真实工具可用时至少运行一次真实工具测试。
