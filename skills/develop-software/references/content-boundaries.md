# 内容边界

适用于文件导入、Base64、本地读取、内容暂存、摘要和重复判断。

## 验证真实字节

1. 已知安全上界时先做廉价预检。
2. 解码或读取时逐块累计，并在超限点停止。
3. 在真实字节层复核最终大小、声明长度和摘要。
4. 聚合输入同时检查单项和总量边界。
5. 测试边界值、边界值加一、非法编码、长度不符、取消和部分读取。

Base64 编码长度只能用于预检，不能替代解码后的真实检查。

## 精确描述一致性

只声明实现真正能观察到的增长、缩短、大小变化、读取字节数或摘要不符。没有快照隔离时，不要声称能识别所有同大小原地重写。取消和 deadline 应覆盖打开、检查、读取、摘要和暂存步骤。

## 分开信号与裁决

摘要、规范化键和字节数是确定性信号；文件名、MIME、大小接近和语义相似度只能形成候选判断。删除、覆盖、合并和正式发布仍由当前 Contract、权限和必要人工决定。

暂存对象或 Candidate 不能描述成已正式提交的 Source／Artifact；正式 ID、验证和原子提交由实际拥有该责任的组件完成。
