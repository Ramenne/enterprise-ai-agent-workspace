# 员工客户端资料属性查询

员工客户端改用已有 POST /v2/materials/workspace-query，取消产品列表 enumerate 全项目资料。新增 attributes 路径等值条件（数组按元素匹配），结构 file_no/扩展属性先过滤，再做当前授权正文/来源校验。新增 known 版本签名映射；rows 模式按有限 ID 回查，响应变化 items、unchanged_ids、project_attributes。签名不含排序位置，page/rows 一致；缺失/移出/当前不可读的请求身份须从缓存移除。

每次 page 最多100结构候选，空页有 continuation 不代表结束；客户端只按用户所需分页。普通刷新对已读窗口条件核对，未变正文不传回；没有单一持久同步游标的虚假保证，也不依赖当前不可靠的共享事件流。after 绑定凭据、项目、筛选，known 不参与绑定；30分钟/进程重启后失效，只重建当前窗口。筛选值按用户请求另行分页发现，保留用户已选项可清除。

没有修改对象存储、正文文件、向量索引、资料分级或登录通知服务。源码/在线接口/构建 UI 与手机验收分开。
