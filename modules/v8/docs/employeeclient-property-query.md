# 员工客户端工作属性查询

`POST /v2/work-items/catalog` 的 page_mode、q、attributes、密封 after 组成有界当前授权查询；结构属性先过滤，再展开必要摘要和来源。保留旧调用，不改向量检索。known 映射已缓存展示签名；work_item_ids 定向回查，响应 items、unchanged_ids、project_attributes 和 next_scan_cursor。未返回的已请求身份应移除。展示签名包含当前授权阶段摘要和属性，不能仅凭主 revision 跳过。

员工客户端最终实现为有界窗口版本签名核对：首次/新条件一页，普通刷新只回查已加载身份并有界核对此前读过的窗口；未变正文不重复返回，失败不提交半页。翻页凭据按凭据/项目/条件绑定30分钟，失效重建当前窗口，禁止当成长期业务同步位置。

真实阶段保存后，共享变更接口仍返回空，不能作为这条产品读取链的可靠依赖。因此已移除本轮候选的额外 checkpoint/query 包装入口；共享原接口和 evidence 权限均未改变，公共事件派发仍是单列平台缺口。员工客户端不为读取建立整项目变更快照，不新增轮询。

## v145 旧 work.search

旧 POST /v2/work-items/search 每次最多展开100个结构匹配候选；未凑满用户数量时也可返回 next_cursor，空页有游标需继续。阶段摘要按 created_at/id 取最新当前授权项，不仅按 work_revision；超出bigint的19位编号正常无匹配。保留当前线上用量/权限包装层，只在唯一识别的搜索核心修改约定片段，迁移在不匹配时拒绝覆盖。新增项目顺序/阶段最近索引。临时表回归与本人正式编号/列表查询已通过。
