# 旧地址读取接续

原创兼容门面，面向迁移试点；不会改变现有域名或旧服务器。`GET /f/:id?v=N` 只能使用人工/Agent 经核对的固定映射；没映射的版本不回落最新。无 `v` 时通过资料存储服务当前 head 解析，再读取精确版本。

- 使用调用者自己的 2.0 Bearer，映射不产生权限，门面没有主控/云密钥或数据库密码。
- 固定版每 128 KiB 重核当前权限；不发匿名 COS URL。已下载的字节无法收回。后续权限丢失会终止剩余发送，客户端应核完整 SHA256/size。
- 不支持旧匿名 `/s/token`、旧 JWT 自动扩权或 Range；需要对应身份桥或新受权分段接口，不能伪装成已无感接入全部播放器/旧客户端。
- manifest 使用 `hub2-legacy-map-v1`，每个旧 ID 绑定一个真实项目与资料、旧数字版本到固定新版本/hash/size，以及核对材料摘要。`coverage:partial` 显式保留未迁版本。

启动：先应用 300 和对应资料存储服务导航接口；用非组/其他人可写、非符号链接的 manifest 文件设置 `HUB_COMPAT_MANIFEST`，执行 `node dist/apps/compat/src/start.js`。缺省仅回环 `4616`，`MEM_URL` 仅允许 HTTPS 或回环。此配置不包含密钥；调用凭据只由实际请求携带。当前自动部署五服务未启用兼容门面，需在下一冻结版按真实映射试点。

接口测试是合成 HTTP 契约，不等于旧资料已迁移。完整 migration 还需要一致快照、资格来源与固定对象核对、单 writer 交接、消费者验证及新写保全。
