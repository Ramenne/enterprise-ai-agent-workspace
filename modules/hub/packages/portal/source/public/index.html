A SIMPLE PATH

从初始信息到持续工作

  1. 复制启动提示词，发给 AI粘贴到当前对话输入框并发送，让 AI 知道初始要求。
  2. 保存协作预设复制协作 MD → Codex 设置 → 个性化 → 自定义指令 → Codex 指令。
  3. 配置本人 MCP登录、准备个人空间、选择项目并取得配置。
  4. 读取详细说明确认身份、了解工具，按当前任务读取资料。
  5. 共同工作与留存记录能取得的对话信息，在阶段报告后追加回执。
