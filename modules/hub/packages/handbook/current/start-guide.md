# 初始接入 · 给成员与 Agent

适用系统版本：2.8.0 · 文档修订：2026-10-18

## 可复制的启动提示词

请使用我的当前 MCP 接入企业 AI 协作平台：`https://hufu.example.invalid/mcp`。沿用已有连接，先调用 `hufu_whoami`、`hufu_context`，优先读取官方 `handbook` 总纲，再从 `function-index` 或说明书目录按本次任务读功能手册和真实工具契约。复用已有项目、工作、资料和对话关联，在本人已有权限内直接推进。缺连接时协助从身份权限服务“身份与软件”取得本人配置，邮箱验证只用邮箱和验证码，不索取邮箱密码。已有项目资格不逐客户端重复申请；缺少实际资格再通过身份权限服务申请。按阶段分别保存成果、报告和有覆盖说明的原文，回执失败保留原提交等待补报，不把计划写成完成。

## 成员开始使用

复制以上提示词给 Agent；已有本人连接可直接使用。没有连接时从身份权限服务“身份与软件”取得配置并保存到本人受控客户端，不把秘密复制进普通日志或报告。

新成员接入链是：复制提示词 → 连接 MCP → 确认身份 → 读总纲 → 按任务查功能手册 → 沿已有工作推进。总纲和回执为软协作约定，明确且权限已知的小任务可先执行后补读。

Agent 最小回报包括当前成员和软件、实际已读说明、已有项目/工作、可执行范围及具体缺口。不要把目录、身份标签或软件历史动作列表当已完成授权证明；同一成员有效 MCP 使用当前已批准项目资格，无需切换项目专用入口。

需要长期协作时可复制 `agent-preset` 作为 AGENTS.md。启动提示词、协作预设和总纲各保留一份正式来源，版本由官方目录固定引用确认。

## 领取实体板任务后
只有任务标题时，让Agent通过任务查询查到内容和方向；不必先创建工程工作或申请AI理解。线下认领有效，线上记录可补记；完成后保存一段自然语言回执即可，不等待主管审核或终端验收。本人在做什么用成员工作清单查询。详情见 `task-points`、`member-work`；同名任务需用实际项目/任务ID区分。

历史版本与变更记录保存在正式发布档案；通过 POST /v2/manuals/read 提供本篇 id 和指定 version 可读取对应冻结正文。
