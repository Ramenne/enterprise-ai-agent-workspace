# 源码与运行范围

适用系统版本：2.7.0 · 文档修订：2026-10-17

当前工程入口是身份权限服务GET /v2/engineering/help与POST /v2/engineering/projects。使用真实project_id查询维护源码、可用动作与资格；经工程status读取维护HEAD、实际部署提交、运行观察及时间。

## 维护入口
|领域|已登记维护源码|实际运行证据|
|---|---|---|
|身份权限服务及公共接入|/srv/workspace
|资料存储服务|/srv/workspace
|V8|/srv/workspace
|其他产品|对应工程登记或团队指定维护入口|对应产品发布与业务观察|

维护源码、构建产物、已部署构件与系统发布清单分别记录。维护HEAD领先部署不等于故障；当前功能由真实接口与部署证据确认，不能用历史文件数、测试数或源码目录代替。
当前可用能力查function-index和具体手册，参数查实时help。未登记、未观察和当前无权分别说明。对某模块的抽样阅读不宣称全公司每个产品逐行审计。

## 能力边界
中枢不保证全客户端完整对话捕获、AI理解永真、所有私人资料自动纳入、所有产品已升级或完整灾备零中断。成员任务事实、派生理解和业务验收分别取证；具体未完成事项留在对应工作，不将过去的未完成清单当作当前全局结论。

历史版本与变更记录保存在正式发布档案；通过 POST /v2/manuals/read 提供本篇 id 和 version:"2.6.2" 可读取整理前正文。
