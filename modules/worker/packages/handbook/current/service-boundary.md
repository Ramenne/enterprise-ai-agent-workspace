# 中枢主控 · 服务职责

适用系统版本：2.7.0 · 文档修订：2026-10-17

主控负责公共基础能力的建设与维护，办理授权，交付可用资源、配置与资料位置，并核验资源本身的可用性。

独立产品通常由所属团队实现业务、集成、构建、部署、运行和验收。用户明确委托主控实施某项目的建设、修改、接线、迁移、部署或验收时，该请求就是对应范围的执行授权，无需再次解除职责限制或重复确认。

资源批准只表示资源范围获准，不自动授权未被委托的产品建设。执行范围存在实质歧义时才澄清；已有明确授权时继续工作。实际身份、项目及服务器权限仍由对应服务校验。

产品自行选择中枢接口和接入深度，拥有自己的业务数据、编号、队列、调度及发布方式。中枢不强制产品采用内部业务表、F编号、V8工作、来源任务、Agent留痕、模型代理、专属密钥、固定发布包装或MCP受控执行。

基础资源核验与产品部署、业务验收分别记录。授权范围内缺少资源时补齐；需要产品实施时按用户委托及真实项目权限执行，不扩大到无关项目。凭据仅经授权通道交付，不进入报告、日志或源码。

历史版本与变更记录保存在正式发布档案；通过 POST /v2/manuals/read 提供本篇 id 和 version:"2.6.2" 可读取整理前正文。
